> 智谱也开源，但是智谱的开源跟我们的开源不一样。智谱的开源有一种被迫的感觉，他们觉得这不是本意 ——梁文峰

## 一、大家都是在蛮荒之境的开发者，大家只是想支持国产

我是最早一批用 GLM 的开发者之一。

讲真的，当时我们是有私心的，或者说以我的角度来说我是有私心的。

我觉得 GLM 可能会成为整个国内开源社区最锋利的矛，同时也可能是最坚韧的盾。虽然它当时的能力并不是最出色的，但我们还是去给它付钱。

原因其实还蛮简单的：它的潜力很大，而且是国产。我们希望在国内能够使用上跟 Claude、GPT 一样的模型。

## 二、能力上来之后，发生了什么

GLM-5 出来之后，模型确实变强了。

然后定价被抬到了一个很高的位置。

商业公司涨价，本身无可指摘。但问题在于涨价的时机和对象：在最需要用户的时候用低价把人拉进来，在不需要用户的时候用高价把人筛出去。对于那些在最差的阶段就付过钱的人来说，这无疑是一种背刺。

## 三、旧套餐被取消

我们的 coding plan 被取消了。

我们被迫接受了智谱的协议。当然它提供了退款说明，只是我们想要的其实并不只是退款，对吧？我们想要没有限制的订阅，想用 GLM 干更多的事情，但是不行，我们被强制迁移了。

讲真的，这件事情跟涨价还不一样。涨价是新的订阅可能会更好，但这其实不是，你给我们画了一个饼，画了一个很优渥的饼，反过来在你真正可以独当一面的时候，又把大家全部抛弃了。

那我真的觉得很过分，对吧？你作为商业公司来说当然没问题，但于情于理，对于我们来说，你干得真的挺够决绝的

## 四、冷处理

当我们有些人在社区里表达不满、试图和你们协商的时候，你们是怎么做的？你们的客服是怎么做的？冷处理，冷处理，还是冷处理。在社区表达不满会被封号，或者被水军攻击。

我不知道啊，你们有那么多时间让你们的运营去当水军，我觉得倒不如多练一练模型，多搞几张卡，也许你们的模型还能更好一点。而不是只能靠所谓的蒸馏，还有所谓的这种 trick、那种 trick，试图来解决所谓的问题。

真的感觉你们和饭圈没什么区别

## 五、Z Code 与生态

Z Code 的产品逻辑很清楚：把开发者的工作流尽可能完整地收进自己的生态里。

这件事本身不是罪。所有平台都想这么干。

但当一家公司已经展示过它会在关键时刻单方面改变规则之后，再让大家把整套开发流程交给它，这个要求就太高了。我们之中的有些人也许会信任你们，但是当你们干出像之前的这些事情的时候，我真觉得我们需要仔细地反思一下，你究竟值不值得信任。

## 六、关于数据

我要明确标注这一段的性质。

我没有内部证据能证明智谱把用户的代码直接用于训练。我说的是推论，依据是：一家做模型的公司，拿到了一个持续产出高质量代码数据的入口，在没有明确、可核验的承诺约束它的情况下，这些数据被用于训练是默认结果，不是例外。

我认为这个推论是成立的。但我不会把它伪装成事实。

我想说的是另一件事：**用户的诉求从来不高。**

我们不关心你的模型是蒸馏的还是自己训的。我们不苛责你的数据集怎么来的。我们大多数人只想要一个便宜、够用、稳定的模型，把手头的活干完。

但"我们要求不高"不等于"我们可以被取用"。不能因为大家只想省钱省事，就把这份将就当成默许——如果你们真的先用廉价的价格把人请过来，之后反过来是为了剥削我们，如果真的是这样，那我们大家不是傻子，我们大家也不会真的一言不发。

你们不应该这样做，对吧？

## 七、结语

我现在用别家的模型了。

我写这些也不是想让谁倒闭。一家国产模型公司能做到今天这个水平，自然是好事。我也真的很希望国内这些公司都能活得平平安安，对吧？毕竟你们是开源社区背后的中坚力量。

但是有一件事情是真的，你们永远都没有办法挽回的，就是开发者社区的信任。

模型可以迭代，价格可以调整，套餐也可以去重做，但是这家公司在关键时刻怎么对待我们，这个判断一旦在社区形成，就很难再改了。

对啊，你可能觉得也无所谓，用户总是会走的，也会有新的客户到来，对吧？“C 端的都是野狗”，对吧？你们的想法是 B 端多好呀，可以吃得肥肥胖胖的。

但是讲真的，那些在你最差的时候掏钱无偿支持你们的人，永远不会再来第二次了
